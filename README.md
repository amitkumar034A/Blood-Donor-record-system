# 🩸 Blood Donor Record Management System

## 📌 About the Project
The Blood Donor Record Management System is a Python-based application designed to manage blood donor information digitally. It helps users register donors, search for donors by blood group or city, update donor details, and maintain donor records efficiently.

## 🎯 Objectives
- Maintain digital records of blood donors.
- Search donors based on blood group and location.
- Reduce the time required to find potential donors.
- Make donor information easy to manage.
- Store records permanently using JSON file handling.

## ⚙️ Features
- Add New Donor
- View All Donors
- Search Donor by ID, Name, Blood Group, or City
- Update Donor Details
- Delete Donor Records
- Blood Group Statistics
- Find Potential Donors

## 🛠️ Technologies Used
- Python
- JSON File Handling
- Lists and Dictionaries
- Functions
- Exception Handling

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:
   ```bash
   cd Blood-Donor-Record-System
   ```

3. Run the Python program:
   ```bash
   python3 main.py
   ```
